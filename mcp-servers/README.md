# Model Context Protocol (MCP) Tool Servers

This directory contains standalone MCP tool servers for InsightForge-AI research agents.

## Servers

- **`web-search/`**: MCP server providing real-time web search, URL fetching, and search synthesis tools.
- **`doc-retrieval/`**: MCP server providing local and remote document retrieval, chunking, and embedding lookups.

MCP tool servers can run as standalone microservices or stdio processes connected to agent orchestrators.
